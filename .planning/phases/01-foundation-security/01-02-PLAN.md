<objective>
Eliminate ~70% duplicate code between APIClient and ZenClient by extracting a shared BaseClient base class.

**Purpose:** The two API client implementations have identical SSE streaming parse loops, message construction, attachment handling, and error handling. Client duplication means bug fixes must be applied twice and adding new providers requires full copy-paste. A shared BaseClient with abstract methods for provider-specific customization solves this.

**Output:**
- `qwen_desktop/core/_base_client.py` — Abstract base class with shared streaming, message construction, attachment handling
- Refactored `api_client.py` — Inherits BaseClient, provides only OpenRouter/DeepSeek/Gemini/custom provider headers + test_connection
- Refactored `zen_client.py` — Inherits BaseClient, provides only OpenCode Zen headers + test_connection
</objective>
