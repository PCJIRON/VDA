    2. **`core/agent_manager/agent_manager.py`** — State machine implementing the Antigravity loop:

       - `class AgentState(enum.Enum)` with values exactly matching research §Pattern 1:
         `IDLE = "idle"`, `INIT = "init"`, `PLAN = "plan"`, `EXECUTE = "execute"`, `VERIFY = "verify"`, `ITERATE = "iterate"`, `COMPLETE = "complete"`, `ERROR = "error"`, `PAUSED = "paused"`
       
       - `class AgentManager:` following research code example:
         - Constructor: `__init__(self, api_client, tool_registry, settings=None, max_iterations: int = 10)`
         - State fields: `self.state = AgentState.IDLE`, `self.plan: list[dict] = []`, `self.current_step: int = 0`, `self.iteration_count: int = 0`, `self.results: list[dict] = []`
         - Subsystem fields: `self.doom_detector = DoomLoopDetector()` and `self.permission_system = PermissionSystem(settings)` created in constructor
         - Internal: `self._error: Optional[str] = None`, `self._paused_reason: Optional[str] = None`
         - `self._user_input: str = ""`, `self._context: str = ""` for passing between steps
       
       - `def reset(self) -> None:` — Reset ALL state to initial values
       
       - `async def step(self) -> tuple[AgentState, Optional[dict]]:` — Execute one state transition. Dispatch pattern using a dict mapping states to handlers:
         ```python
         _handlers = {
             AgentState.INIT: _handle_init,
             AgentState.PLAN: _handle_plan,
             AgentState.EXECUTE: _handle_execute,
             AgentState.VERIFY: _handle_verify,
             AgentState.ITERATE: _handle_iterate,
             AgentState.COMPLETE: _handle_complete,
             AgentState.ERROR: _handle_error,
         }
         ```
         
       - Each handler returns `(next_state, Optional[dict])`:
         - `_handle_init()`: Set iteration_count, transition to PLAN
         - `_handle_plan()`: Call `_create_plan(task, context)` via LLM → sets self.plan. Transition to EXECUTE
         - `_handle_execute()`: If all steps done, VERIFY. Else get current step, return with step info. Transition to VERIFY after tool execution
         - `_handle_verify()`: Call `_verify_result()` via LLM. If success → advance step; if all done → COMPLETE, else → EXECUTE. If fail → ITERATE
         - `_handle_iterate()`: Check `self.iteration_count >= self.max_iterations`. If exceeded → ERROR("max_iterations"). Else increment and retry EXECUTE
         - `_handle_complete()`: Return final results
         - `_handle_error()`: Return error message
       
       - `def pause(self, reason: str) -> None:` — Set PAUSED state, store reason
       - `def resume(self) -> None:` — Restore to EXECUTE or previous state
       - `def abort(self) -> None:` — Set state to COMPLETE (abort)
       
       - Private helpers:
         - `async def _create_plan(self, task: str, context: str) -> list[dict]:` — Call LLM via api_client to decompose task. Reuses existing TaskDecomposer prompt pattern but returns agent-style plan: `[{"step": "...", "tool": "...", "args": {...}, "expected": "..."}]`
         - `async def _verify_result(self, result: dict) -> dict:` — Call LLM to check if step outcome matches expected result. Returns `{"success": bool, "reason": str}`
       
       - Module-level logger: `logger = logging.getLogger(__name__)`
       - Follow existing patterns: Service class initialized with api_client, async methods, Google-style docstrings

    DO NOT create the AgentWorker QThread here — that's Plan 04. AgentManager is a pure state machine testable without PyQt.

    - `@dataclass class ToolCallRecord:` with fields:
      - `name: str`
      - `args_hash: str`
      - `result_hash: str`
      - `timestamp: float`

    - `class DoomLoopDetector:` with:
      - `__init__(self, threshold: int = 3, window_size: int = 10)` — Uses `deque(maxlen=window_size)` for rolling history per research §Don't Hand-Roll
      - `@staticmethod def _hash(obj: dict) -> str:` — `hashlib.md5(json.dumps(obj, sort_keys=True, default=str).encode()).hexdigest()`
      - `def record_call(self, tool_name: str, args: dict, result: str) -> None:` — Create ToolCallRecord with name + args_hash + result_hash + timestamp, append to deque. Log via `logger.debug(f"[Doom] Recorded: {tool_name} args={record.args_hash[:8]}")`
      - `def check_loop(self) -> Optional[dict]:` — Check last N (self.threshold) calls. Return None if fewer than threshold entries. Compare `name`, `args_hash`, AND `result_hash` of all threshold entries (per research §Pitfall 2 — includes result_hash to prevent false positives on polling). If all three match → return `{"tool": first.name, "count": self.threshold, "first_at": recent[0].timestamp, "last_at": recent[-1].timestamp}`. Log via `logger.warning(...)`. Otherwise return None.
      - `def clear(self) -> None:` — Clear the deque

    - Key design per research:
      - Uses `collections.deque(maxlen=10)` — O(1) append/popleft, fixed size
      - Compares (name, args_hash, result_hash) triple — result_hash prevents false positives on polling (per §Pitfall 2)
      - Args hashed via `hashlib.md5` with sorted JSON keys for deterministic comparison

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| AgentManager step() → LLM API | AI-generated plans and verification results cross from untrusted LLM into execution logic |
| PermissionSystem → Tool call | Permission check gates every tool invocation — mutation/destructive tools require explicit ASK |
| DoomLoopDetector → AgentManager | Detection triggers PAUSED state, blocking further tool execution |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-04 | Denial of Service | AgentManager max_iterations | mitigate | Hard limit from Settings (default 10). AgentManager transitions to ERROR when exceeded — prevents infinite API spend. |
| T-02-05 | Tampering | PermissionSystem config | mitigate | Permission levels read from AGENT_TYPES in defaults.py (not runtime-mutable dict). Sub-agents inherit scoped permissions. |
| T-02-06 | Tampering | DoomLoopDetector false negatives | accept | Result-hash comparison prevents polling false positives. Edge case: tool that returns same result for different state (rare). Mitigated by also having max_iterations as last resort. |
| T-02-07 | Spoofing | _create_plan LLM output | accept | LLM-generated plans are validated by _verify_result after each step. Malformed plans caught at tool execution. |
| T-02-SC | Tampering | No packages installed | mitigate | This plan installs NO new packages. All code uses Python stdlib + existing stack. Slopcheck bypass valid. |
</threat_model>
