## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| String-replace edit dropped method definition | When inserting `_format_results` via edit tool using `oldString` of `def _handle_api(self, text, attachments):`, the replacement removed the method definition line, causing AttributeError at runtime. | blocking | When inserting code near method boundaries, always verify complete surrounding lines (including the `def` line) are preserved in both oldString and newString. Read back 5+ lines below the edit target before writing. |
| AgentWorker emits no streaming chunks | Switching from APIServerWorker (streaming) to AgentWorker (signal-based) broke the streaming response display. `_on_api_chunk` was never called because AgentWorker has no chunk signal. | advisory | When replacing a worker class, check all signal connections the UI expects. If missing signals, adapt the connection pattern rather than leaving dead code. |
