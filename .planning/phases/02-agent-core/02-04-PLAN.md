    - `class AgentWorker(QThread):` — EXACTLY matching research §Pattern 2 signal definitions:

      ```python
      class AgentWorker(QThread):
          # Step-level updates
          step_started = pyqtSignal(str, str)        # (step_label, tool_description)
          step_completed = pyqtSignal(str, str, str)  # (step_label, status, result_preview)
          step_failed = pyqtSignal(str, str)          # (step_label, error_message)

          # Plan-level
          plan_created = pyqtSignal(list)              # full plan steps
          status_changed = pyqtSignal(str)             # current state name
          finished = pyqtSignal(object)                # final result

          # Doom loop (per D-04)
          doom_loop_detected = pyqtSignal(str, str)    # (tool_name, args_summary)

          # Permission (for ASK decisions)
          permission_required = pyqtSignal(str, str, str)  # (tool_name, args, agent_type)

          # Compaction
          compaction_needed = pyqtSignal(int, int)     # (current_tokens, max_tokens)

          # Errors
          error_occurred = pyqtSignal(str)
      ```

      - `__init__(self, agent_manager, user_input, context="")`:
        - `super().__init__()`
        - Store `self._agent_manager` and input/context
        - `self._paused = False` flag for doom loop pause

      - `def run(self):` — Follow existing pattern:
        ```python
        def run(self):
            try:
                asyncio.run(self._run_loop())
            except Exception as e:
                logger.error(f"[AgentWorker] Fatal error: {e}", exc_info=True)
                self.error_occurred.emit(str(e))
        ```

      - `async def _run_loop(self):` — Main agent loop:
        1. Set state to INIT via `self._agent_manager.step()` 
        2. Loop: call `self._agent_manager.step()` until COMPLETE or ERROR
        3. On each state transition, emit appropriate signals:
           - `INIT`: emit `status_changed("init")`
           - `PLAN`: emit `status_changed("plan")`, then when plan created → emit `plan_created(plan)`
           - `EXECUTE`: get current step, emit `step_started(step_label, tool_description)`. Execute tool via ToolRegistry. If tool returns error → emit `step_failed()`, else emit `step_completed()`. After tool call, call `doom_detector.record_call()` and `check_loop()`. If loop detected → emit `doom_loop_detected()`, set `self._paused = True`, wait until resume/abort called.
           - `VERIFY`: emit `status_changed("verify")`. After verification → emit step result.
           - `COMPLETE`: emit `finished(results)` and `status_changed("complete")`
           - `ERROR`: emit `error_occurred(message)` and `status_changed("error")`
           - `PAUSED`: emit `status_changed("paused")` and wait
         4. Check SessionCompactor.needs_compaction after each step → emit `compaction_needed` if true
         5. If compaction needed and `compacted` signal response received: call `compactor.compact()` → write compacted result to SessionService (session_service.update_conversation(messages))

      - `def pause_for_doom_loop(self, tool_name, args_summary):` — Set flag, wait
      - `def resume_from_doom_loop(self):` — Call `self._agent_manager.resume()`, clear pause flag
      - `def abort_agent(self):` — Call `self._agent_manager.abort()`, clear pause flag
      - `def handle_permission_response(self, tool_name, allowed):` — Cache decision and continue

    - Key design per research anti-patterns:
      - Thin QThread wrapper — business logic stays in AgentManager (testable without PyQt)
      - Uses `asyncio.run()` inside `run()` — matches APIServerWorker pattern exactly
      - All state owned by AgentManager — not split between worker and manager

    - Update `core/agent_manager/__init__.py`:
      ```python
      from qwen_desktop.core.agent_manager.agent_worker import AgentWorker
      ```
      And add `"AgentWorker"` to `__all__`.

| T-02-SC | Tampering | No packages installed | mitigate | This plan installs NO new packages. All code uses Python stdlib + existing PyQt6 stack. Slopcheck bypass valid. |
