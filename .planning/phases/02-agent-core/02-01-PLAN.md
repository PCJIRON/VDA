    3. **`core/tool_registry/registry.py`** — ToolRegistry following the existing CommandRegistry pattern:
       - `class ToolRegistry:` with:
         - `__init__`: Initialize `_registry: dict[str, type[BaseTool]]`, `_instances: dict[str, BaseTool]`, `_locks: dict[str, threading.Lock]`
         - `def register(self, name: str, tool_cls: type[BaseTool]) -> None:` — store class reference, create Lock. Log via `logger.debug(f"[ToolRegistry] Registered: {name}")`
         - `def get_tool(self, name: str) -> Optional[BaseTool]:` — Double-checked locking pattern for thread-safe lazy init (per research §Lazy Tool Loading):
           ```python
           if name not in self._instances:
               with self._locks[name]:
                   if name not in self._instances:
                       self._instances[name] = self._registry[name]()
                       logger.info(f"[ToolRegistry] Initialized: {name}")
           return self._instances.get(name)
           ```
         - `def get_definitions(self, agent_type: Optional[str] = None) -> list[dict]:` — Returns OpenAI-compatible function schemas. If `agent_type` provided, filter by `_get_tool_allowlist(agent_type)`. Each definition has the schema: `{"type": "function", "function": {"name": cls.name, "description": cls.description, "parameters": cls.parameters}}`
         - `def get_definitions_for_tools(self, tool_names: list[str]) -> list[dict]:` — Returns schemas only for the specified tool names
         - `def is_loaded(self, name: str) -> bool:` — Check if instantiated
         - `def loaded_count` and `registered_count` properties
         - `def get_agent_type_tools(self, agent_type: str) -> list[str]:` — Returns tool names allowed for a given agent type. Reads from AGENT_TYPES config: `self._settings.get("agent_types", {}).get(agent_type, {}).get("tools", [])` if settings available, else returns all tool names
         - `def _get_tool_allowlist(self, agent_type: str) -> list[str]:` — Internal: reads tool allowlist from config
         - Constructor optionally accepts `settings` parameter for config-backed agent type tool filtering
       
       - Module-level singleton accessor:
         ```python
         _registry = ToolRegistry()
         def register_tool(name: str):
             def decorator(cls):
                 cls.name = name
                 _registry.register(name, cls)
                 return cls
             return decorator
         def get_registry() -> ToolRegistry:
             return _registry
         ```

    Follow conventions: snake_case methods, PascalCase class, module-level logger, full package-path imports.
    Import `threading` (stdlib) and `typing.Optional`, `typing.List` for type hints.

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Elevation of Privilege | ToolRegistry.get_definitions(agent_type) | mitigate | Scope filtering by agent_type prevents tools from being exposed to wrong sub-agents. Allowlist defined in AGENT_TYPES config. |
| T-02-02 | Denial of Service | ToolRegistry.get_tool() lazy init with lock | mitigate | Double-checked locking prevents race conditions. Lock is per-tool, so one slow init doesn't block other tools. |
| T-02-03 | Tampering | tool_registry/__init__.py exports | accept | Module-level singleton is overwritable but this is a single-process desktop app. Risk is low — setting a bad singleton only affects current session. |
| T-02-SC | Tampering | No packages installed | mitigate | This plan installs NO new packages. All code uses Python stdlib + existing stack (PyQt6, httpx). Slopcheck not required. |
</threat_model>
